Inside a machine
THE WHOLE MACHINE

Every part depends on the others.

Change one part and five others may have to change. Scroll, and we take the machine apart the way we check it.

01 · PROCESSOR

Not cores alone

We compare processors on speed per core as well as the number of cores. A server chip with many slow cores can feel slower in Excel than a desktop chip.

02 · MOTHERBOARD

The board decides the rest

Which processors it supports, how many slots it has, which cabinet it fits. A part the board cannot take is blocked, and we tell you why.

03 · MEMORY

Fill the channels

The same memory spread across more channels runs faster. We show how many channels each build fills.

04 · GRAPHICS

Graphics memory decides AI

For AI work, the memory on the graphics card decides which models run fast on the machine. We show that for each card.

05 · POWER AND STORAGE

Room to spare

We add up the power at full load and pick a supply with headroom. Storage, cooling and the cabinet are checked the same way.
