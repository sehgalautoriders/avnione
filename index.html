01 · AVNI CLOUD

Connected infrastructure

Our files and records live in the cloud, not on one computer. Any of our machines can pick up the work where another left it.

02 · AVNI CORE

Core runs every job. Each change is built, tested and installed through one release line. Every install gets its own number and a way back.
